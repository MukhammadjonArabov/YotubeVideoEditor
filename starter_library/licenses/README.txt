Starter library for AutoExplainer
==================================
music/  - 16 tracks from FreePD.com (public domain, CC0 1.0), re-encoded to 128 kbps MP3.
          Source dataset: https://github.com/SoundSafari/CC0-1.0-Music (freepd.com folder).
          Crediting is not required; "Music: FreePD.com" in the description is a nice courtesy.
sfx/    - ding/pop/click/question: Kenney Interface Sounds + UI Audio (CC0 1.0), see kenney-*.txt.
          whoosh/swoosh/riser/boing/impact: synthesized from scratch for this project (CC0 1.0).
Always double-check licences yourself before monetizing; YouTube Content ID can still
occasionally flag public-domain music that someone else registered - dispute it with this note.
